Ключ доступа

Токен GitHub с правом Contents: read and write. Хранится только в этом браузере — на сервер не уходит и никому не показывается.

Открыть редактор

Если ключа ещё нет

  1. Откройте страницу создания токена.
  2. Repository access → Only select repositories → выберите portfolio.
  3. Permissions → Repository permissions → Contents → Read and write.
  4. Срок действия — на ваше усмотрение. Когда истечёт, просто создайте новый и вставьте сюда.
  5. Скопируйте ключ и вставьте в поле выше. Показывается он один раз.
Ключ — это и есть настоящая защита. Страница лежит в публичном репозитории, поэтому её адрес не является секретом: любой может её открыть. Но без ключа он не сможет ничего опубликовать — правки останутся в его собственном браузере и никого, кроме него, не коснутся. Не вставляйте ключ на чужом компьютере и не пересылайте его в переписке. Если он всё-таки куда-то попал — отзовите и создайте новый.

Как это работает

  1. Нажмите Открыть редактор.
  2. Плюсик на пустой ячейке — выберите видео. Оно сразу уходит в репозиторий.
  3. Тексты правятся прямо на странице — кликните и печатайте.
  4. Save в нижней панели — и сайт обновился для всех.

Работает с ноутбука и с телефона одинаково. Ничего скачивать и раскладывать по папкам не нужно. Размер одного видео — до 45 МБ.
